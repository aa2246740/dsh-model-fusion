# dsh-model-fusion 0.2.4

Supports DeepSeek Harness **0.2.0-rc.2**.

Fix the installation instructions that still selected the older DSH 0.1.7-compatible plugin tag. Install this release in the official Desktop plugin manager using:

```text
github:aa2246740/dsh-model-fusion#v0.2.4
```

The prebuilt `.tgz` below can also be downloaded and installed as a local package. Choose the plugin archive, not GitHub's Source code archive.

This is an installation-documentation correction. Runtime bundles are unchanged from the previous RC2-compatible release; DSH peers remain `>=0.2.0-rc.1 <0.2.1`. No new Windows/Linux runtime validation is claimed.
